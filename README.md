# Shopping App

Shopping App est une application web complète pour la gestion des achats en ligne. Elle inclut une partie backend pour gérer l'authentification, les utilisateurs, les rôles et les commandes, ainsi qu'une partie frontend pour l'interface utilisateur.

---

## 🎯 Fonctionnalités principales
- Gestion des utilisateurs avec rôles (`admin`, `seller`, `user`).
- Authentification sécurisée avec JWT.
- Gestion des commandes et des produits.
- Interface utilisateur intuitive pour les clients et les administrateurs.

---

## 🛠️ Technologies utilisées

### Backend
- **Node.js** avec **Express.js**
- Base de données **MongoDB** (via **Mongoose**)
- Sécurisation avec **JWT** et **bcrypt**
- Gestion des emails (optionnel avec **Nodemailer**)

### Frontend
- **React.js** pour l'interface utilisateur
- **React Router** pour la navigation
- **Bootstrap** pour le design
